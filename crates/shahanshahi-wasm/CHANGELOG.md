## [0.1.0] - 2026-06-05

First release.

### Added

- `gregorianToShahanshahi(year, month, day)` — converts a Gregorian date to Shahanshahi, returns `{ year, month, day }` or throws on invalid input ([#70](https://github.com/melliran/shahanshahi/pull/70))
- `shahanshahiToGregorian(year, month, day)` — converts a Shahanshahi date to Gregorian, returns `{ year, month, day }` or throws on invalid input ([#70](https://github.com/melliran/shahanshahi/pull/70))
- `isShahanshahiLeapYear(year)` — returns `true` if the Shahanshahi year is a leap year (Mode A arithmetic rule) ([#70](https://github.com/melliran/shahanshahi/pull/70))
- TypeScript definitions auto-generated by `wasm-pack`
- Published to crates.io as `shahanshahi-wasm` and to npm as `@melliran/shahanshahi-wasm`
